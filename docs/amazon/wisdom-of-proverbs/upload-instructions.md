# Uploading this — The Wisdom of Proverbs (B0HHW7WXG7)

Everything needed is in this folder. Nothing here changes price, categories,
keywords or ads.

## 1. The description (2 minutes)

1. KDP → Bookshelf → the hardcover → **⋯ → Edit paperback/hardcover details**.
2. Replace the Description field with the contents of `description.html`.
   Paste the HTML, not the plain text — KDP's description box accepts
   `<p>`, `<b>`, `<ul>` and `<li>`, which is all this uses.
   `description.txt` is the same words without markup, for anywhere that
   refuses HTML.
3. Leave title, subtitle, author, keywords and categories untouched.
4. Save and **Publish** that edit. A description change goes live in about
   72 hours and does not create a new edition.

## 2. The A+ content (15 minutes)

1. KDP → Marketing → **A+ Content Manager** → Start creating A+ content.
2. Language/marketplace: English, and include **Amazon.de** — that is where
   this ASIN lives. Add the other English marketplaces too if offered; the
   same modules apply.
3. Add three modules in this order, taking headline and body text from
   `aplus/module-copy.md` word for word:
   - **Standard Image Header with Text** → `module-1-cover.jpg`
   - **Standard Three Images & Text** → the three `module-2-img-*.jpg` files,
     in the order listed in the copy file
   - **Standard Image Header with Text** → `module-3-six-steps.jpg`
4. Apply to ASIN **B0HHW7WXG7**. If the paperback should carry it too, add
   that ASIN in the same step.
5. **Do not submit yet.** Look at the preview on the phone layout first —
   that is where the page previews have to stay readable.

Amazon review takes up to seven days. A+ content appears under the
description, replacing nothing.

- `module-2-img-1-reading.jpg` — "Day 1 page showing Today's Reading, Proverbs 1"
